# ANFIS with Explainable AI (XAI) for Diabetes Prediction

[![Python](https://img.shields.io/badge/Python-3.8%2B-blue)](https://www.python.org/)
[![PyTorch](https://img.shields.io/badge/PyTorch-1.10%2B-orange)](https://pytorch.org/)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

This repository contains a PyTorch-based **GPU-only** implementation of the Adaptive Neuro-Fuzzy Inference System (ANFIS), integrated with Explainable AI (XAI) techniques to provide interpretable predictions for diabetes.

## 🎯 Use Cases
- **Medical Diagnosis Classification** (Diabetes Prediction)
- **High-Performance Training** (PyTorch GPU optimization)
- **Interpretability** (Extracting fuzzy rules, SHAP feature importance)
